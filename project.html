jQuery is a JavaScript library that simplifies selecting elements, handling events and changing a web page.

For example, a button can hide a paragraph with .hide().

A selector tells jQuery which elements to work with.

$("#title") selects an ID, $(".item") selects a class, and $("p") selects paragraph tags.

.animate() gradually changes numeric CSS properties, such as width, height, left and opacity.

Several properties in one call change together. Chained calls run one after another by default.

This accordion uses .slideToggle() for a smooth opening and closing effect.
