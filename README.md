## Run the project

1. Download and extract the project folder.
2. Open `index.html` in a browser.
3. Use the navigation bar to open each part.

An internet connection is required because every page loads the full jQuery 3.7.1 library from `https://code.jquery.com/jquery-3.7.1.min.js`. No installation, build command, or backend is required.

Open the browser's developer tools and select **Console** to see `jQuery is ready!`.
